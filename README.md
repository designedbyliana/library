# Designed by Liana — Дизайн-библиотека

Адаптивный одностраничный сайт для GitHub Pages. Чистые HTML, CSS и JavaScript — сборка и установка зависимостей не нужны.

## Как опубликовать на GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в корень репозитория `index.html`, `styles.css`, `script.js`, папки `assets` и `files`.
3. В репозитории открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажми **Save**.
5. После публикации GitHub покажет адрес сайта.

## Что заменить перед запуском

### 1. Файлы PowerPoint

Положи реальные файлы в папку `files` и назови их:

- `template-01.pptx`
- `template-02.pptx`
- `template-03.pptx`

Или измени `href` у соответствующих кнопок в `index.html` на прямые ссылки из облачного хранилища. Сейчас карточки содержат демонстрационные описания и визуальные макеты, а не реальные презентации.

### 2. Социальные сети

В `index.html` найди `REPLACE_ME` и замени заглушки на реальные адреса Telegram, YouTube, TikTok и VK. Удали площадки, которыми не пользуешься.

### 3. Шрифт TAN Meringue

Положи лицензионный файл шрифта в `assets/TAN-Meringue.woff2`. Если файл называется иначе, поменяй путь в начале `styles.css`. Пока файл шрифта не добавлен, заголовки используют элегантный системный serif-шрифт. Montserrat подключается через Google Fonts; для офлайн-работы можно добавить локальные файлы Montserrat и заменить подключение.

### 4. Контент шаблонов

В карточках замени названия, описания, количество слайдов и превью на реальные данные. Сейчас три обложки сделаны средствами CSS как временные макеты, чтобы сайт уже выглядел цельно до добавления готовых файлов.

## Структура

- `index.html` — все блоки страницы и тексты.
- `styles.css` — фирменные цвета, типографика, стеклянные эффекты, адаптивность и анимации.
- `script.js` — горизонтальная прокрутка, мобильное меню, анимация появления и интерактивность.
- `assets/` — локальные шрифты и дополнительные изображения.
- `files/` — готовые PPTX-файлы.

## Доступность и производительность

Есть адаптация под мобильные устройства, управление каруселью клавиатурой, семантические элементы, состояния фокуса браузера и поддержка `prefers-reduced-motion`.
